# Stability Matrix

### The unified manager for AI image generation platforms

Stability Matrix is a one-stop launcher and package manager for Stable Diffusion UIs including Automatic1111, ComfyUI, Forge, and more. Manage models, extensions, and updates across all platforms from one clean interface.

<br>

---

## Features

| | |
|:---|:---|
| **Multi-Platform** | Manage AUTOMATIC1111, ComfyUI, Forge, InvokeAI, and Fooocus together |
| **Model Browser** | Download CivitAI and Hugging Face models directly from the app |
| **One-Click Updates** | Keep all your UIs and extensions updated with a single click |
| **Portable Mode** | Run from a USB drive for a completely portable AI generation setup |
